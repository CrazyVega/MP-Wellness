# Backend - MAGALY HEALING HANDS

## Descripción

El backend del proyecto **MAGALY HEALING HANDS** fue desarrollado utilizando **Python**, **Django** y **Django REST Framework**, implementando una arquitectura basada en API REST para la gestión de citas, usuarios y servicios terapéuticos.

El sistema permite administrar usuarios con diferentes roles, controlar el agendamiento de citas, gestionar historiales básicos de pacientes y manejar autenticación segura mediante JWT.

---

## Tecnologías utilizadas

* Python
* Django
* Django REST Framework
* JWT Authentication
* SQLite / PostgreSQL
* Django Filters
* Git y GitHub

---

## Funcionalidades principales

* Registro e inicio de sesión de usuarios
* Autenticación con JWT
* Gestión de roles:

  * Administrador
  * Cliente
  * Terapeuta
* CRUD de servicios
* Sistema de citas
* Confirmación y cancelación de citas
* Gestión de estados:

  * Pendiente
  * Confirmada
  * Finalizada
